# Автоматизированные интеграционные тесты API (Postman)

Репозиторий содержит коллекцию end-to-end (e2e) тестов для REST API интернет-магазина, разработанного на платформе .NET.

## Архитектура коллекции

- Папка CRUD Products: Тестирование базового жизненного цикла товара (POST, GET, SOFT DELETE).
- Папка End-to-End Cart & Order: Интеграционный сценарий покупки, включающий создание товаров, инициализацию корзины, добавление номенклатуры по динамическим ID и финальное оформление заказа.

## Технологический стек и подходы

- Изоляция сценариев по логическим директориям (Folders).
- Использование динамических переменных окружения и коллекции для исключения хардкода идентификаторов.
- Автоматический парсинг JSON-ответов в секции Scripts / Post-res.
- Тестовое покрытие: валидация статус-кодов (200 OK, 201 Created), проверка типов данных и структуры JSON-пакетов.

## Инструкция по запуску

### Вариант 1: Через графический интерфейс Postman

1. Импортировать файлы коллекции и окружения через кнопку Import.
2. Выбрать активное окружение online-store-qa в правом верхнем углу.
3. Запустить пакетный прогон через Collection Runner.

### Вариант 2: Через консольный интерфейс (для CI/CD автоматизации)

Для запуска требуется установленная утилита Newman.

Установка:
npm install -g newman

Запуск тестов:
newman run online-store-qa.postman_collection.json -e online-store-qa.postman_environment.json
